The Comprehensive Assessment Project is the capstone of my graduate work in strength and conditioning. The premise is straightforward: you can't program intelligently for athletes you haven't measured. The execution is harder — getting the right tests, run consistently, by people other than yourself, on athletes whose seasons don't pause for science.

This project documents the assessment system I designed for Colby-Sawyer College: which tests, why those tests, how to run them efficiently across a roster, and how to read the results without overinterpreting them.

The full PDF is below. The short version: build a small set of high-signal tests, train your staff to run them the same way every time, and use the data to ask better questions — not to make decisions you'd otherwise have made on instinct.
